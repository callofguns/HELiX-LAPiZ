Every knob says what it does

Controls have a plain name on top and the real synth term underneath, so you can start making sounds right away and learn the proper words as you go. They're colored by where they sit in the sound, the same as in LAPiZ, so you can follow it from left to right. Hover over anything in LAPiZ and the help bar explains it.

    Always the newest version

    From version 1.2, LAPiZ updates itself. When you open it, it quietly checks for a new version, downloads it and installs it in the background while you keep making music. The bar at the bottom tells you when it's done: restart FL Studio and you're on the new version. No installer to run and no admin prompt.

    • Safe. Updates only come from LAPiZ's own releases on GitHub, and each download is checked before it's installed. If anything goes wrong, your current version stays as it was.
    • Your choice. Open the gear menu to turn automatic updates off, or click Check for updates now.
    • On version 1.1 or older? Install 1.2 once using the steps below. Updates are automatic from then on.

    Install

    LAPiZ runs on 64-bit Windows in FL Studio or any other music software that loads VST3 plugins.

    1. Download LAPiZ-1.3.0-setup.exe from the latest release on GitHub.

    2. Run it. Windows may warn that the app is from an unknown publisher, because LAPiZ isn't code-signed yet. Click More info, then Run anyway.

    3. In FL Studio, open Options > Manage plugins and click Find installed plugins.

    4. Find LAPiZ in the list (made by HELiX) and click its star. It now shows up in the plugin browser and the Channel Rack's + menu.

    That's the only time you need to install it. New versions arrive by themselves.

    Prefer to build it yourself? The README on GitHub has the steps. You need Visual Studio Build Tools and CMake.
